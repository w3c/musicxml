## Draft

## Schema Additions

### New Elements

*   The [`<part-symbol>`](../../musicxml-reference/elements/part-symbol/) element now has cardinality 0..N instead of 0..1, to allow grouping staves in multiple groups within a part. ([Issue 572](https://github.com/w3c-cg/musicxml/issues/572))

*   The [`<coda>`](../../musicxml-reference/elements/coda/) and [`<segno>`](../../musicxml-reference/elements/segno/) elements in [`<barline>`](../../musicxml-reference/elements/barline/) now have cardinality 0..N instead of 0..1, same as their cardinality within [`<direction-type>`](../../musicxml-reference/elements/direction-type/). ([Issue 653](https://github.com/w3c-cg/musicxml/issues/653))

*   The [`<accidental>`](../../musicxml-reference/elements/accidental/) and [`<key-accidental>`](../../musicxml-reference/elements/key-accidental/) elements now have cardinality 0..N instead of 0..1, to support microtonal music. ([Issue 605](https://github.com/w3c-cg/musicxml/issues/605))

### New Attributes

*   The `@number` attribute has been added to the [`<harmonic>`](../../musicxml-reference/elements/harmonic/) element to accommodate multiple harmonics per chord. ([Issue 529](https://github.com/w3c-cg/musicxml/issues/529))

### New Values

*   None so far

## Removed and Deprecated Features

*   The timewise format and [`<score-timewise>`](../../musicxml-reference/elements/score-timewise/) element are now deprecated. ([Issue 483](https://github.com/w3c-cg/musicxml/issues/483))

## Documentation Changes

*   None so far
