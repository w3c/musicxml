## Removed and Deprecated Features

*   The timewise format and <score-timewise> elements are deprecated and will be removed in two versions (#483)
*   _(Deprecated in 4.0, to be removed in 5.0)_:
*   The DTD versions of the MusicXML definitions have been deprecated in favor of the XSD versions. This includes the midixml DTD and XSL files, which will not be replaced with XSD versions. ([Issue 401](https://github.com/w3c-cg/musicxml/issues/401))
