title: Version 4.0
---
## Released June 2021

## Packaging Changes

*   MusicXML 4.0 specifies a standard way to represent both score and parts in a single compressed .mxl file. ([Issue 278](https://github.com/w3c-cg/musicxml/issues/278))
*   MusicXML 4.0 now contains a standard [XML catalog](../../listings/catalog.xml/) to make local validation easier. ([Issue 259](https://github.com/w3c-cg/musicxml/issues/259))
*   MusicXML 4.0 now contains W3C XML Schema versions of the [container](../../listings/container.xsd/) and [sounds](../../listings/sounds.xsd/) document definitions, replacing the deprecated DTD versions. ([Issue 401](https://github.com/w3c-cg/musicxml/issues/401))

## Schema Additions

### New Elements

*   The [<assess>](../../musicxml-reference/elements/assess/) element specifies how default assessment should be overridden for individual notes. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))
*   The [<bass-separator>](../../musicxml-reference/elements/bass-separator/) element indicates that text, rather than a line or slash, separates the bass from what precedes it. ([Issue 307](https://github.com/w3c-cg/musicxml/issues/307))
*   The [<concert-score>](../../musicxml-reference/elements/concert-score/) element indicates that a score is displayed in concert pitch. ([Issue 39](https://github.com/w3c-cg/musicxml/issues/39), [Issue 279](https://github.com/w3c-cg/musicxml/issues/279))
*   The [<first>](../../musicxml-reference/elements/first/) element represents the first of two consecutive notes in a swing ratio. ([Issue 283](https://github.com/w3c-cg/musicxml/issues/283))
*   The [<for-part>](../../musicxml-reference/elements/for-part/) element is used in a concert score to indicate the transposition for a transposed part created from that score. ([Issue 279](https://github.com/w3c-cg/musicxml/issues/279))
*   The [<instrument-change>](../../musicxml-reference/elements/instrument-change/) element represents a change to the virtual instrument sound for a given [<score-instrument>](../../musicxml-reference/elements/score-instrument/). ([Issue 293](https://github.com/w3c-cg/musicxml/issues/293))
*   The [<line-detail>](../../musicxml-reference/elements/line-detail/) element specifies the appearance of a line in the staff. ([Issue 305](https://github.com/w3c-cg/musicxml/issues/305))
*   The [<listen>](../../musicxml-reference/elements/listen/) element specifies different ways that a score following or machine listening application can interact with a performer. It represents interactions that are specific to a note. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))
*   The [<listening>](../../musicxml-reference/elements/listening/) element specifies different ways that a score following or machine listening application can interact with a performer. It represents interactions that change the state of the listening application from the specified point in the performance onward. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))
*   The [<note>](../../musicxml-reference/elements/note/) element may now contain multiple [<instrument>](../../musicxml-reference/elements/instrument/) elements. ([Issue 277](https://github.com/w3c-cg/musicxml/issues/277))
*   The [<numeral>](../../musicxml-reference/elements/numeral/) element represents the Roman numeral or Nashville number part of a harmony. It requires that the key be specified in the encoding. ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The [<numeral-alter>](../../musicxml-reference/elements/numeral-alter/) element represents an alteration to the [<numeral-root>](../../musicxml-reference/elements/numeral-root/). ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The [<numeral-fifths>](../../musicxml-reference/elements/numeral-fifths/) element specifies the reference key for the [<numeral>](../../musicxml-reference/elements/numeral/) in the same way as the [<fifths>](../../musicxml-reference/elements/fifths/) element. ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The [<numeral-key>](../../musicxml-reference/elements/numeral-key/) element is used when the key for the [<numeral>](../../musicxml-reference/elements/numeral/) is different than the key specified by the key signature. ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The [<numeral-mode>](../../musicxml-reference/elements/numeral-mode/) element specifies the scale that is used to interpret the [<numeral-root>](../../musicxml-reference/elements/numeral-root/) element values. ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The [<numeral-root>](../../musicxml-reference/elements/numeral-root/) element represents the Roman numeral or Nashville number as a positive integer from 1 to 7. ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The [<other-listen>](../../musicxml-reference/elements/other-listen/) element represents other types of listening control and interaction that are specific to a note. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))
*   The [<other-listening>](../../musicxml-reference/elements/other-listening/) element represents other types of listening control and interaction that change the state of the listening application from the specified point in the performance onward. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))
*   The [<part-clef>](../../musicxml-reference/elements/part-clef/) element is used for transpositions from concert scores that also include a change of clef, as for instruments such as bass clarinet. ([Issue 55](https://github.com/w3c-cg/musicxml/issues/55))
*   The [<part-link>](../../musicxml-reference/elements/part-link/) element allows MusicXML data for both score and parts to be contained within a single compressed MusicXML file. It links a [<score-part>](../../musicxml-reference/elements/score-part/) from a score document to MusicXML documents that contain parts data. ([Issue 278](https://github.com/w3c-cg/musicxml/issues/278))
*   The [<part-transpose>](../../musicxml-reference/elements/part-transpose/) element specifies the transposition for a transposed part created from the existing score file. ([Issue 279](https://github.com/w3c-cg/musicxml/issues/279))
*   The [<player>](../../musicxml-reference/elements/player/) element allows for multiple players per [<score-part>](../../musicxml-reference/elements/score-part/) for use in listening applications. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))
*   The [<second>](../../musicxml-reference/elements/second/) element represents the second of two consecutive notes in a swing ratio. ([Issue 283](https://github.com/w3c-cg/musicxml/issues/283))
*   The [<straight>](../../musicxml-reference/elements/straight/) element specifies that no swing is present, so consecutive notes have equal durations. ([Issue 283](https://github.com/w3c-cg/musicxml/issues/283))
*   The [<swing>](../../musicxml-reference/elements/swing/) element specifies whether or not to use swing playback, where consecutive on-beat / off-beat eighth or 16th notes are played with unequal nominal durations. ([Issue 283](https://github.com/w3c-cg/musicxml/issues/283))
*   The [<swing-style>](../../musicxml-reference/elements/swing-style/) element describes the style of swing used. ([Issue 283](https://github.com/w3c-cg/musicxml/issues/283))
*   The [<swing-type>](../../musicxml-reference/elements/swing-type/) element specifies the note type, either eighth or 16th, to which the [<first>](../../musicxml-reference/elements/first/) to [<second>](../../musicxml-reference/elements/second/) ratio is applied. ([Issue 283](https://github.com/w3c-cg/musicxml/issues/283))
*   The [<sync>](../../musicxml-reference/elements/sync/) element specifies the style that a score following application should use the synchronize an accompaniment with a performer. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))
*   The [<wait>](../../musicxml-reference/elements/wait/) element specifies a point where the accompaniment should wait for a performer event before continuing. ([Issue 294](https://github.com/w3c-cg/musicxml/issues/294))

### New Attributes

*   The arrangement attribute has been added to the [<bass>](../../musicxml-reference/elements/bass/) and [<harmony>](../../musicxml-reference/elements/harmony/) elements. ([Issue 307](https://github.com/w3c-cg/musicxml/issues/307))

*   The multiple-rest-always and multiple-rest-range attributes have been added to the [<measure-numbering>](../../musicxml-reference/elements/measure-numbering/) element. ([Issue 310](https://github.com/w3c-cg/musicxml/issues/310))
*   The offset attribute has been added to the [<release>](../../musicxml-reference/elements/release/) element. ([Issue 203](https://github.com/w3c-cg/musicxml/issues/203))
*   The placement attribute have been added to the [<figured-bass>](../../musicxml-reference/elements/figured-bass/) element. ([Issue 336](https://github.com/w3c-cg/musicxml/issues/336))
*   The print-object attribute has been added to the [<metronome>](../../musicxml-reference/elements/metronome/) element. ([Issue 355](https://github.com/w3c-cg/musicxml/issues/355))
*   The scaling attribute has been added to the [<staff-size>](../../musicxml-reference/elements/staff-size/) element. ([Issue 305](https://github.com/w3c-cg/musicxml/issues/305))
*   The shape attribute has been added to the [<bend>](../../musicxml-reference/elements/bend/) element. ([Issue 306](https://github.com/w3c-cg/musicxml/issues/306))
*   The smufl attribute has been added to the [<effect>](../../musicxml-reference/elements/effect/), [<membrane>](../../musicxml-reference/elements/membrane/), [<metal>](../../musicxml-reference/elements/metal/), [<timpani>](../../musicxml-reference/elements/timpani/), and [<wood>](../../musicxml-reference/elements/wood/) elements. *   The smufl attribute has been added to the [<wavy-line>](../../musicxml-reference/elements/wavy-line/) element. ([Issue 397](https://github.com/w3c-cg/musicxml/issues/397))
*   The staff attribute has been added to the [<measure-numbering>](../../musicxml-reference/elements/measure-numbering/) element. ([Issue 23](https://github.com/w3c-cg/musicxml/issues/23))
*   The system attribute has been added to the [<direction>](../../musicxml-reference/elements/direction/), [<ending>](../../musicxml-reference/elements/ending/), [<harmony>](../../musicxml-reference/elements/harmony/), and [<measure-numbering>](../../musicxml-reference/elements/measure-numbering/) elements. ([Issue 37](https://github.com/w3c-cg/musicxml/issues/37))
*   The text attribute has been added to the [<inversion>](../../musicxml-reference/elements/inversion/) element. ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The type attribute has been added to the [<level>](../../musicxml-reference/elements/level/) element. ([Issue 288](https://github.com/w3c-cg/musicxml/issues/288))
*   The unbroken attribute has been added to the [<arpeggiate>](../../musicxml-reference/elements/arpeggiate/) element. ([Issue 281](https://github.com/w3c-cg/musicxml/issues/281))

### New Values

*   The [smufl-accidental-glyph-name](../../musicxml-reference/data-types/smufl-accidental-glyph-name/) type used by the smufl attribute of the [<accidental>](../../musicxml-reference/elements/accidental/), [<accidental-mark>](../../musicxml-reference/elements/accidental-mark/), [<accidental-text>](../../musicxml-reference/elements/accidental-text/), and [<key-accidental>](../../musicxml-reference/elements/key-accidental/) elements now allows SMuFL accidental glyphs from the [Medieval and Renaissance accidentals](https://www.w3.org/2021/03/smufl14/tables/medieval-and-renaissance-accidentals.html) and [Kievan square notation](https://www.w3.org/2021/03/smufl14/tables/kievan-square-notation.html) ranges. ([Issue 330](https://github.com/w3c-cg/musicxml/issues/330))
*   The part name value has been added to the list of standard [<credit-type>](../../musicxml-reference/elements/credit-type/) element values. ([Issue 282](https://github.com/w3c-cg/musicxml/issues/282))
*   The inverted-bracket value has been added to the [enclosure-shape](../../musicxml-reference/data-types/enclosure-shape/) type, used by the enclosure attribute. ([Issue 308](https://github.com/w3c-cg/musicxml/issues/308))
*   Eight new sound IDs have been added to the sounds.xml file for use by the [<instrument-sound>](../../musicxml-reference/elements/instrument-sound/) element. They are wind.flutes.whistle.tin.c ([Issue 289](https://github.com/w3c-cg/musicxml/issues/289)) and drum.tabor, drum.tamborim, pitched-percussion.handchimes, pluck.cavaquinho, wind.reed.clarinet.d, wind.reed.clarinet.g, and wind.reed.clarinet.piccolo. ([Issue 363](https://github.com/w3c-cg/musicxml/issues/363))
*   Element content for the [<ipa>](../../musicxml-reference/elements/ipa/) element has been updated to IPA 2015 symbols represented in Unicode 13.0. ([Issue 345](https://github.com/w3c-cg/musicxml/issues/345))
*   The highest value for the [number-level](../../musicxml-reference/data-types/number-level/) type, used by the number attribute, has been raised from 6 to 16. ([Issue 297](https://github.com/w3c-cg/musicxml/issues/297))
*   The discontinue value has been added to the [pedal-type](../../musicxml-reference/data-types/pedal-type/) type, used by the type attribute of the [<pedal>](../../musicxml-reference/elements/pedal/) element. ([Issue 302](https://github.com/w3c-cg/musicxml/issues/302))
*   The resume value has been added to the [pedal-type](../../musicxml-reference/data-types/pedal-type/) type, used by the type attribute of the [<pedal>](../../musicxml-reference/elements/pedal/) element. ([Issue 335](https://github.com/w3c-cg/musicxml/issues/335))

## Removed and Deprecated Features

*   The DTD versions of the MusicXML definitions have been deprecated in favor of the XSD versions. This includes the midixml DTD and XSL files, which will not be replaced with XSD versions. ([Issue 401](https://github.com/w3c-cg/musicxml/issues/401))
*   Empty [<multiple-rest>](../../musicxml-reference/elements/multiple-rest/) elements are no longer allowed. This was a mistake in the original definition of the element. ([Issue 249](https://github.com/w3c-cg/musicxml/issues/249))
*   The [<function>](../../musicxml-reference/elements/function/) element is deprecated as of MusicXML 4.0. Use the [<numeral>](../../musicxml-reference/elements/numeral/) element instead. ([Issue 295](https://github.com/w3c-cg/musicxml/issues/295))
*   The none value in the [clef-sign](../../musicxml-reference/data-types/clef-sign/) type used by the [<sign>](../../musicxml-reference/elements/sign/) element is deprecated as of MusicXML 4.0. ([Issue 304](https://github.com/w3c-cg/musicxml/issues/304))
