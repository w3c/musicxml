---
title: 'system attribute (only-top)'
elements:
- direction
- direction-type
- words
description: The only-top value of the system attribute indicates that the `<direction>` element should only appear of the top staff of the system.
---
```xml
<direction directive="yes" placement="above" system="only-top">
   <direction-type>
      <words default-y="40" font-size="10" font-weight="bold">Andantino</words>
   </direction-type>
</direction>
```
